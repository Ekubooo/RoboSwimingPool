# 三种流体渲染模式：实现与必要验证

日期：2026-11-15。只改 RSP/rendering 及专用检查/性能工具；后端、求解器、策略、PD、流体配置和资产管线未改。

## 实现

- Original 默认启用，原 billboard.py 和原 shaders.py 未修改，不分配可选模式的离屏纹理。
- Transparent 保留方形粒子与速度配色，使用加权 OIT、速度透明度和一个物理粒子半径宽度的深度淡化。
- SSFR 使用球面深度/厚度、双边滤波、法线重建、吸收、Fresnel、天空/环境反射及屏幕空间折射。
- UI 下拉框提交切换请求；下一帧应用，暂停也可切换。新模式首次分配资源，后续复用；Reset 保留模式。
- 可选路径共用单个 CUDA–GL 粒子实例缓冲；只更新当前路径，场景输入和合成输出分离。模型更换/关闭先解除注册再删除 GL 缓冲。

## 测量条件与口径

RTX 5070，1280×720，299,475 粒子，种子 1234，同一策略、初始状态、相机与渲染参数。每模式一个独立进程，预热 30 帧、采样 180 帧一次。未执行录像测试、长稳定性测试或多轮采样。

## GPU 绘制归因

下表同为均值 / P50 / P95，单位 ms。使用 GL_TIMESTAMP，全部采样结束并完成 GPU 工作后统一读取查询。GPU 数据与 CPU 墙钟重叠，不加入上表。

| GPU 范围 | Original | Transparent | SSFR |
|---|---:|---:|---:|
| Newton 场景绘制 | 0.398 / 0.385 / 0.397 | 0.189 / 0.188 / 0.204 | 0.197 / 0.185 / 0.197 |
| 新增流体通道 | — | 0.404 / 0.404 / 0.432 | 0.506 / 0.505 / 0.524 |
| 完整场景及流体合成 | 0.398 / 0.385 / 0.398 | 0.627 / 0.615 / 0.649 | 0.726 / 0.712 / 0.740 |

Original 的 Newton 场景绘制包含旧粒子；新模式的这一项只含原场景几何，新流体另列。完整范围还包括最终纹理/窗口拷贝，因此不能把完整范围与它的子项重复相加。UI 不在上述 GPU 场景范围内。

相对 Original：Transparent 整帧均值增加约 0.232 ms，SSFR 增加约 0.290 ms；对应完整场景 GPU 时间增加约 0.229 / 0.328 ms。这是当前相机、分辨率与场景下的一次测量，不是所有视角的上界。近景覆盖面积和粒子层数都会影响额外开销。

- 真实 CUDA/GL 定向测试通过：透明度阈值 0/2/4.25/6.5/20 m/s；三模式切换；固定场景切回 Original 逐像素一致；粒子状态不变；默认 Original 无新离屏资源。
- 检查暂停相机重绘、窗口尺寸变化、初始化失败保留旧模式、模型更换释放注册、重复关闭及 UI 原有快捷键。
- 每个实际播放进程在计时区间外禁止 Warp `.numpy()` 并执行普通帧，通过；新增渲染目录静态审计无 `.numpy()`、`.cpu()`、像素/纹理/缓冲回读及显式 GPU 同步。初始化查询 GL 状态与 GPU 图像拷贝不属于仿真状态回读。
- 截图在计时区间外保存。已检查透明方形粒子、刚体遮挡及 SSFR 水面/折射；这是基础 SSFR，细碎粒子仍可能出现闪亮边缘，屏幕外物体不参与折射。流体离屏目标为单采样，复用解析后的 MSAA 场景。
- 没有逐帧仿真 CUDA Graph 重建；未修改物理时间或控制设置。
