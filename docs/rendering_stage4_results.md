# 演示路径精简与约 30 万粒子：验证结果

日期：2026-11-15。

代码精简在原粒子规模下使整帧均值下降 **26.5%**；新默认配置比改动前下降 **23.2%**。

## 改动与边界

- 精简 UI 保留播放、重置、场景球策略开关、相机和显示控制；移除模型/重力/诊断面板及池边线。
- 专用播放循环复用原策略接口，移除测试回报统计、结束查询和逐帧自动重置；环境停止训练历史与先验特征更新。
- 原策略输入公式、归一化、GSI 初始化和重置保留；固定场景球占位张量在 GPU 缓存。
- 默认半径 0.01 m、2 子步、3 压力迭代；水块高度 0.50–2.08 m，301,392 粒子。速度/返力倍率 0.2/1。
- 控制 30 Hz、刚体 240 Hz：每控制帧刚体 8 步、流体在第 4/8 步各推进 1/300 s，共 1/150 s。
- 后端仅修改获批的可选场景绘制回调接线；数值求解器、控制/坐标/力观测路径和资产管线代码不变。新 0.04 m 支撑半径的体积映射使用原缓存流程生成。

RTX 5070，1280×720，VSync 关闭，窗口隐藏但场景与 UI 正常绘制；相同策略与种子 1234。每组 3 个独立进程，每种模式预热 30 帧、测量 180 帧（合计 540 样本）。缓存生成、截图和状态检查不在计时内。A 调用原 `_rollout_test`，B/C 调用实际 `PlaybackRunner`。

## 正确性与稳定性

- 31 项单元检查通过：15 项渲染、5 项时钟/反馈、9 项后端回归、2 项播放契约。
- 与 A 组归档环境实现比较：4 个状态 × 2 种场景球输入，共 8 组；策略输入及动作最大误差均为 0（阈值 rtol=1e-5、atol=1e-6）。
- 普通播放帧禁用 Warp numpy、Torch cpu/item 读出和训练特征调用后继续正常运行；两帧 CUDA/Torch 跟踪中 D2H 事件为 0。初始化、重置、拾取和截图等显式操作不在这一结论范围内。
- 实际 UI 暂停、单步、延迟重置、反馈清空、快捷键、相机和显示开关通过。渲染单测覆盖胶囊端帽、动态颜色、遮挡、拾取、模型切换与窗口关闭资源顺序。
- SMP 检查点、GSI 重置通过。历史上验证过 8 帧非空的 854×480 录像；按后续要求已清理录像测试产物，今后不再测试录像功能。
- Graph 与普通执行：API/模型元数据相同（仅执行模式标记不同），630 项快照中 602 项逐位一致、24 项在严格容差内、4 项速度相关数组超出 rtol=1e-5 / atol=1e-6。粒子位置最大差 0.24 微米，粒子速度最大差约 0.000060 m/s；时钟和刚体步数全部一致。
- 同一 Graph 在独立进程重复也有 5 项数组超出该严格容差，速度偏差同为约 0.000060 m/s，表明存在浮点非确定性。保留失败记录，不宣称所有轨迹数组严格等价，也未为此改动求解器。这与“同一状态下策略输入/动作误差为 0”的检查不同。
- 连续 1,800 帧：主时钟 60 s、流体时钟 12 s；粒子、人形、策略输入与反馈均为有限值。
- **已发现的限制：3 / 301,392 粒子越界（约 0.001%）**，10–60 s 检查点数量保持 3；其余画面未见整体发散。越界粒子最远下降到 z≈-68.19 m。因此不能宣称完全无穿透；本轮按边界没有修改求解器或加入位置修正。
