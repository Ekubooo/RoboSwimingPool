# 流体交互面板与高水块恢复

日期：2026-11-15。只做本次相关检查，无录像测试、录像产物或全套回归。

## 实现与边界

- 原面板只保留 Pause、Step、Reset、Policy: scene sphere。相机、右键拖拽和录像接口保留。
- 新增流体重力强度 0～20 m/s²（默认 9.81，释放滑条后应用）、返力倍率 0～2（默认 1，实时应用）、Fluid slow motion ×0.5。
- G 反转流体重力；O/P 选择世界 −X/+X，再次按相同方向恢复 −Z；G 清除左右切换记录。X 切换流体半速。键盘捕获、长按去重、松键及失焦处理均接入现有窗口。
- R 和面板 Reset 共用请求入口：恢复向下重力 9.81、倍率 1、正常速度；重置场景、时钟和返力缓存，清除单步请求并暂停。Scene sphere 选择保留，程序首次启动仍自动运行。
- 半速只把流体的两个积分步从各 1/300 s 改为各 1/600 s。返力仍按实际 dt 计算，再乘倍率，不补偿慢放导致的变化。人形重力、策略 30 Hz、每五帧决策、刚体 4×1/600 s、PD 和压力迭代 3 次保持原值。
- `RSP/runtime/interaction.py` 保存 CPU 设定值，UI 和键盘共用操作。播放循环在帧边界应用。返力倍率使用持久 GPU 缓冲；重力和步长变化使 Graph 失效，下次推进前重建。重建保留计数器、流体累计时间和预测缓冲交换关系；失败时暂停并显示错误。
- 右侧水块世界边界为 X=1.56～2.96、Y=0.75～1.90、Z=0.50～2.08 m，共 **301,392 粒子**。人形仍从左侧地面初始化，不抬到水块上方。
- 根据实施中的明确授权，仅修改 `newton_pbf_runtime.py` 的启动布局检查：允许与初始水块及内部静态兔子重叠，保留池壁越界和动态刚体之间的重叠检查。求解器、运行时碰撞、粒子生成规则和资产算法不改，缓存复用。

## 必要检查

17 项不同的定向测试通过，覆盖控制状态、键盘捕获与去重、实际 OpenGL 面板、重置顺序、默认粒子数、时钟、Graph 恢复及初始化检查。后续仅针对新增检查和发现的测试条件问题补测，没有重复整套稳定性或性能测试。

- 实际播放检查通过 R／Reset、暂停／单步、Scene sphere 保留、返力倍率 0／2／1、重力方向与慢放切换。
- 每帧仍调用刚体 4 次、流体 2 次；普通执行与 Graph 的时钟、调用次数及缓冲交换一致。重力、PD 参数数组及策略间隔未变化。
- 同初态单步对比固定已有 GSI 缓冲的采样游标和刚体计数器，仅用于诊断，未改生产初始化。重力反转、半速、2 倍返力同时启用时：粒子集合最大双向最近点距离 **9.83×10⁻⁷ m**，刚体状态最大绝对差 **9.20×10⁻⁹**。粒子会重新排序，因此不直接比较粒子数组下标。
- 初步交互轨迹两次 reset 使用了不同 GSI 样本，其终态差值不代表 Graph 数值误差；报告中的独立同初态检查才用于数值一致性判断。

### 回读审计

- 新增控制器、面板和调度热路径没有 `numpy()`、`cpu()`、`item()` 状态回读。
- 10 个真实播放／调整帧拦截了 Warp `numpy()`、GPU→CPU `wp.copy`、Torch `cpu()` 和 `item()`；覆盖普通帧、返力变化、重力变化和慢放，全部通过。
- 另取 5 帧 CUDA trace，覆盖策略决策、普通绘制及返力更新：**D2H 事件 0，cudaStreamSynchronize 事件 0**。
- UI 显示 CPU 设定值，返力只在值变化时更新 GPU 参数。初始化、诊断、截图和按需拾取不包含在该“常规帧无回读”结论中。
- CUDA–GL 互操作及交换显示仍可能等待 GPU；无回读不等于完全无等待。

### 高水块短运行

600 帧，即 **4 秒主时钟**。初始根位置约 `(0.65, 1.0, 0.9035)`；原 GSI 姿态与速度保留。

| 检查时刻 | 粒子越界 | 静态边界内部粒子 | 最高粒子 Z |
|---|---:|---:|---:|
| 初始 | 0 | 1,112 | 2.060 m |
| 1 s | 0 | 0 | 2.501 m |
| 2 s | 0 | 0 | 2.949 m |
| 3 s | 0 | 0 | 1.389 m |
| 4 s | 0 | 0 | 2.111 m |

检查点的粒子、速度、刚体、关节、观测和返力均有限。初始重叠按要求保留；初始 772 个粒子位于静态边界内部超过一个粒子半径。之后各检查点静态穿透数为零。画面表现为较强溃坝及飞溅，人形随后被水流推倒；这不是“持续站稳”验证，也不是长期稳定性结论。没有因此调整求解器、返力、PD 或位置修正。

## 单轮性能对比

两组使用独立进程、相同策略／种子 1234、1280×720、MSAA 4、阴影开启、vsync 关闭；隐藏窗口仍执行实际 UI 和 GL 渲染。各预热 30 帧、采样 180 帧，仅一轮。截图、诊断及同步检查在计时区间外。

A：改动前低水块 300,105 粒子；B：新交互面板与高水块 301,392 粒子。**对比同时包含水块布局和物理轨迹变化，不能单独归因为 UI 优化。**

下表单位为 ms，每格为 **均值／P50／P95**。分项为不重叠的 CPU 墙钟区间；均值可相加为整帧，分位数不能直接相加。

| 分项 | A：改动前 | B：改动后 |
|---|---:|---:|
| 策略推理 | 0.0660 / 0.0000 / 0.3342 | 0.0712 / 0.0000 / 0.3729 |
| 动作处理 | 0.0704 / 0.0689 / 0.1050 | 0.0925 / 0.0937 / 0.1311 |
| 仿真提交 | 0.5033 / 0.4870 / 0.6720 | 0.5578 / 0.5372 / 0.7217 |
| 观测后处理 | 0.0778 / 0.0732 / 0.1076 | 0.0963 / 0.0884 / 0.1454 |
| 渲染调用，含等待 | 8.2122 / 8.2582 / 10.4389 | 7.8855 / 7.9323 / 10.1569 |
| 其他 | 0.0636 / 0.0596 / 0.0873 | 0.0813 / 0.0757 / 0.1156 |
| **整帧** | **8.9933 / 8.9933 / 11.2568** | **8.7845 / 8.7685 / 11.0061** |

策略每五帧才推理，所以 P50 为零。限帧等待为零。包含批次末尾 GPU／GL 完成等待的均摊耗时为 **9.0346 → 8.8337 ms**，约 **110.7 → 113.2 FPS**；不与整帧再次相加。

UI 构建＋绘制调用合计约 **0.419 → 0.459 ms**，增加约 **0.040 ms**；整帧本轮减少约 **0.209 ms**，单轮结果不代表稳定的加速保证。重力／慢放改变后的 Graph 重建单独测得 **24.77～32.31 ms**，可能产生短暂停顿；返力滑条不重建 Graph。这里没有重新做长时间 GPU 分段诊断。
