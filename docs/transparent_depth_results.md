# 透明 billboard 深度明暗与不透明度 UI

## 实现

- 业务代码仅修改 RSP/rendering；另更新必要测试、性能工具和说明。Original、SSFR、求解器、后端及资产管线均未作本轮修改。
- 默认不透明度为 80%～100%；最低值滑条限制 60%～80%，最高值滑条限制 80%～100%，步长均为 1%。速度过渡仍为 2～6.5 m/s。
- 深度效果默认开启，强度默认 0.5，可调 0～1。该强度下近端亮度倍率 1.05、远端 0.75，中间 smoothstep 插值；强度为 0 或关闭时恢复未调色的 OIT 颜色。白色近端可能因亮度上限而裁切。
- 仅自动范围，没有手动近远距离。使用可见流体的加权线性相机深度，经 GPU 2×2 min/max 归约得到近远范围，无逐帧 GPU→CPU 状态读回。空画面或近乎平面范围不做明暗调整。
- 原 OIT 权重、背景透射率乘积、几何遮挡和无交界淡化行为不变。明暗只乘到归一化流体颜色，再与未修改的背景合成。
- 设置在帧边界应用，暂停时也能调整；CPU 仅保存 UI 设定值。关闭或强度为 0 时跳过范围归约通道，已分配的资源缓存复用；缩放时重建、关闭时释放。
- 自动范围随当前相机和可见流体变化，没有时间滤波。切换视角或极端远近粒子进出画面时，整片流体的明暗范围可能随之变化。

## 必要检查

- 三项定向真实 CUDA/GL 检查通过：近亮远暗、强度零恢复原像素、空白背景不变；1% 量化和滑条边界；正常深度遮挡与无交界淡化。
- 验证暂停调整、奇数分辨率缩放归约至 1×1、无状态读回、切回 Original 固定场景逐像素一致。颜色设置不改变 SSFR 参数。
- 实际播放普通帧在禁止 Warp .numpy() 下通过；截图及 GPU 查询读取放在计时区间外。没有录像测试、录像文件或长稳定性测试。

## 性能

RTX 5070，1280×720，498,456 粒子，沿用工作区现有黏性 0.35（本轮未修改）。相同策略、随机种子 1234、初始配置与相机；效果关闭/开启各一个独立进程，预热 30 帧，采样 180 帧一次。两组均为不透明度 80%/100%，隔离深度效果的增量成本。

单位 ms，表内为均值 / P50 / P95。CPU 分项互斥，均值可相加；各分位数不能相加。

| CPU 墙钟 | 关闭 | 开启（强度 0.5） |
|---|---:|---:|
| 策略 | 0.071 / 0.000 / 0.326 | 0.066 / 0.000 / 0.337 |
| 动作处理 | 0.072 / 0.070 / 0.128 | 0.072 / 0.068 / 0.112 |
| 仿真提交 | 0.476 / 0.445 / 0.684 | 0.499 / 0.461 / 0.623 |
| 观测 | 0.075 / 0.068 / 0.102 | 0.077 / 0.069 / 0.106 |
| 渲染调用（含等待） | 11.396 / 11.454 / 13.713 | 11.562 / 11.628 / 13.503 |
| 其他 | 0.062 / 0.057 / 0.083 | 0.062 / 0.057 / 0.081 |
| 整帧 | 12.151 / 12.123 / 14.392 | 12.338 / 12.316 / 14.215 |

GPU 时间通过 GL_TIMESTAMP 在全部采样结束后读取。它们与 CPU 墙钟重叠，不能加入整帧；完整场景项包含其子项。

| GPU 范围 | 关闭 | 开启 |
|---|---:|---:|
| Newton 场景 | 0.187 / 0.188 / 0.195 | 0.188 / 0.188 / 0.196 |
| 透明流体通道 | 0.499 / 0.497 / 0.533 | 0.663 / 0.660 / 0.711 |
| 完整场景与流体合成 | 0.732 / 0.708 / 0.750 | 0.874 / 0.871 / 0.926 |

本次开启效果：整帧均值增加约 **0.188 ms**（约 1.5%），透明流体 GPU 通道增加约 **0.164 ms**。单次测量存在系统波动，不代表所有视角；约 11 ms 的 CPU 渲染调用包含等待，不等于实际绘制时间。
