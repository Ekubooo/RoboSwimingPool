# 透明 billboard 单层开关

UI 的 `Transparent layer blending` 默认开启，保留原加权 OIT。
关闭时用独立深度缓冲选出每像素最近的正方形面片，然后只合成一次：
`颜色 = 粒子颜色 × 不透明度 + 不透明场景颜色 × (1 − 不透明度)`。
后方粒子不贡献颜色或不透明度。速度配色、不透明度滑条、自动深度明暗与场景遮挡保留。
运行中或暂停时均在帧边界应用，不改变仿真 Graph、时间或状态。

改动仅涉及渲染实现，以及定向测试、性能工具和说明。Original、SSFR、后端、求解器和资产管线没有本轮改动。
单层离屏目标按需分配并缓存；缩放和关闭时释放颜色纹理、深度 renderbuffer。
没有 CPU 粒子排序或逐帧状态回读。同深度面片采用先绘制者，最近粒子更替仍可能造成颜色跳变或显露方形边界。

## 必要验证

- 单层中心像素等于最近粒子的速度颜色乘自身不透明度；更换绘制顺序结果一致。
- 60%/80% 不透明度、恢复叠加、暂停热切换、背景不变、刚体遮挡均通过。
- 正常帧禁止 Warp `.numpy()` 时通过；独立深度缓冲随尺寸变化释放并重建，无 GL 错误。
- 现有自动深度明暗检查，以及 Original/SSFR 模式与状态一致性检查通过。
- 画面检查使用计时外截图；未测试录像，未运行完整仿真或触发新墙厚资产烘焙。

## 性能

RTX 5070，1280×720，499,200 个静止合成粒子，半径 0.01 m，含前景遮挡盒。
固定相机，速度用于配色但不积分位置；不透明度 80%～100%，深度明暗开启、强度 0.5。
同一进程，每种设置各预热 30 帧、采样 180 帧一次。GL 时间戳统一在采样结束后读取。

单位 ms，均值 / P50 / P95：

| 范围 | 开启叠加 | 关闭叠加（最近单层） |
|---|---:|---:|
| 渲染帧 CPU 墙钟，含粒子更新和显示提交 | 1.045 / 1.005 / 1.292 | 0.904 / 0.857 / 1.130 |
| 透明流体 GPU 通道，含深度明暗和合成 | 0.620 / 0.619 / 0.620 | 0.437 / 0.436 / 0.437 |

GPU 通道均值减少约 0.183 ms。两类时间重叠，不能相加。
此场景不含策略、物理和 UI，不能替代完整播放整帧时间；结果随遮挡、视角和粒子分布变化。
第一次进入透明模式的完成帧约 231.46 ms（包含初始化），随后第一次关闭叠加约 3.54 ms（包含独立目标分配与一帧绘制），不计入常规帧。
